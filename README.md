# Empirical Evaluation of the MISH Hotel Information System

This repository contains the R scripts used for the empirical analyses conducted as part of my Master’s thesis:

“Empirical Evaluation of the MISH Hotel Information System”

Faculty of Informatics
Juraj Dobrila University of Pula

About the Research

The study evaluates the MISH hotel information system, developed by Istra Tech, from the perspective of employees who use the system in their daily work.

The research integrates the DeLone and McLean Information Systems Success Model and the Technology Acceptance Model (TAM).

The final analytical sample consists of 69 respondents and 31 retained indicators measuring six reflective constructs:

* INFOQ – Information Quality
* SYSQUAL – System Quality
* SERVQUAL – Service Quality
* PU – Perceived Usefulness
* PEOU – Perceived Ease of Use
* SAT – User Satisfaction

Repository Contents

MISH_PLS_SEM_analysis.R

Main R script used to perform the statistical analyses reported in the thesis.

The script includes:

* Data import, preparation, and cleaning
* Descriptive statistics
* Assessment of ceiling effects
* Cronbach’s alpha
* Common method bias diagnostics
* Harman’s single-factor test
* Full-collinearity VIF assessment
* PLS-SEM measurement model assessment
* Reliability and convergent validity
* HTMT discriminant validity
* Structural model assessment
* R² and f² assessment
* Collinearity assessment
* Bootstrap analysis
* Hypothesis testing
* Mediation analysis
* Comparison of Model C and Model B
* Importance–Performance Map Analysis (IPMA)
* PLSpredict analysis
* Necessary Condition Analysis (NCA)
* NCA bottleneck analysis
* Generation of figures used in the thesis

MISH_capture_results.R

Supporting script used after the main analysis has been completed.

The script collects the main statistical outputs generated by MISH_PLS_SEM_analysis.R and saves them into:

MISH_results_capture.txt

The captured results include descriptive statistics, measurement and structural model results, bootstrap estimates, mediation results, model comparison, IPMA results, NCA results, and information about the R environment.

Primary Structural Model

The primary model used in the thesis is Model C.

Its structural relationships are:

* INFOQ → PU
* SYSQUAL → PU
* SERVQUAL → PU
* SERVQUAL → PEOU
* PU → SAT
* PEOU → SAT

An alternative Model B is also estimated and compared with Model C.

Software

The analyses were conducted in R.

The main packages used include:

* seminr – PLS-SEM estimation
* NCA – Necessary Condition Analysis
* psych – descriptive statistics and reliability analysis
* ggplot2 – data visualization

Additional packages are used for data manipulation, visualization, and result processing.

Reproducibility

Bootstrap inference is based on 5,000 resamples with a fixed random seed:

set.seed(123)

The NCA procedure uses 1,000 permutations.

PLSpredict is performed using 10-fold cross-validation with 10 repetitions.

Using a fixed random seed helps ensure reproducibility of procedures involving random resampling.

Data

The research dataset is not included in this repository.

The scripts therefore require the appropriate MISH survey dataset to reproduce the complete analysis.
